What's New in IP Traffic Spy 1.0.1

IPv6

  • IPv4 and IPv6 traffic is captured at the same time on the adapter you choose.
  • IPv6 extension headers (hop-by-hop, routing, fragment, destination options, authentication) are understood.
  • Filters accept IPv6 addresses and CIDR blocks. Host names are resolved for IPv6 addresses too.

Filters

  • CIDR blocks (10.0.0.0/8) and port ranges (1024-65535).
  • Advanced Rules: combine conditions with AND - addresses, ports, protocol, TCP flags, host names and payload text - and match either direction.
  • A new option to require every filter group to match, instead of any.
  • Host name rules like host example.com now match the site's real addresses, not just reverse DNS.
  • Filters are remembered between sessions, can be saved to and loaded from files, and there are one-click presets.
  • Right-click filters for conversations, remote IP / port / host and protocol, plus "Remove Filters Matching This Packet".
  • Apply Filters To Grid and Clear All Filters on the Filters menu.
  • The status bar shows how many filters are active and how many packets they have hidden.

Data Grid

  • New columns: Direction, Flags, TTL, IP version, Frag and Matched By.
  • DNS, HTTP and TLS packets show a readable summary in the Text column (for example the DNS name asked for, the HTTP request line and Host, or the TLS server name).
  • Host names are now looked up for every address seen, even for packets your filters hide. The program's own lookups are kept out of the grid, and identical lookups are no longer repeated.
  • New Actions menu options: Auto-Scroll and DNS Lookups can be switched on and off, and a new Filters option, Hide This Program's Own DNS Lookups.
  • Larger packets (up to 64 KB) are captured instead of being dropped, and memory use is capped.

Packet Details

  • A decoded pane: IPv4/IPv6, TCP (with options), UDP, ICMP/ICMPv6, DNS, HTTP and TLS handshakes.
  • A real hex dump with offsets and an ASCII gutter.
  • Prev / Next buttons to step through packets without closing the dialog.

Fixes

  • Pausing is now reliable on a busy network: pausing no longer stalls, and dialogs no longer reopen unexpectedly.
  • Several threading problems that could cause crashes or hangs (host name cache, clearing the grid) were fixed.
  • Host names stop filling in once the grid was full - fixed.
  • Port filters now validate their input, and Save Data to a .csv file now really is comma separated and includes a Protocol heading.
  • Selecting the first row in the grid now works with all the right-click commands.
