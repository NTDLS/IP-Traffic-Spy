Whats IP Traffic Spy for?

IP Traffic Spy is for the curious and the extremely paranoid, as well as those who are developing communication software such as Web servers & firewalls.

Some things it is good at:

  • Seeing exactly what a program sends and receives, and who it talks to.
  • Debugging your own network software: ports, flags, resets, fragments and payloads.
  • Checking what is, and is not, encrypted - the Text column shows readable data, and TLS connections show the server name they are connecting to.
  • Watching DNS lookups to see which names a machine is resolving.
  • Spotting unexpected or unwanted traffic leaving your computer.
  • Locating weak points in your security and network communications / encryption.

Please read Privacy & Responsible Use. Only monitor networks and computers you own or have permission to monitor.
