Getting Started

1. Run as administrator

See Requirements. Without administrator rights Windows will not let the program read packets.

2. Choose a connection

When the program starts it asks which address to bind to. The list shows the IPv4 and IPv6 addresses of every network adapter that is currently up. Pick the address on the adapter you want to watch and press Ok.

  • Choosing any address watches that adapter: both its IPv4 and IPv6 traffic are captured.
  • You can also type an address that is not in the list; then only that single address is bound.
  • To switch adapters later use File > Change Connection.
  • Cancel at startup closes the program.

The left part of the status bar shows Connected to ... once capture is running, or an explanation if it could not start.

3. Watch the grid

Packets appear in the Data Grid as they arrive. Press the Space Bar to pause and read; press it again to resume (packets that pass while paused are not recorded).

4. Narrow things down

Right-click a packet and use Filters to include or exclude things like its remote host, port or protocol, or press I / E to open the Include / Exclude dialogs. On a network full of background noise, Filters > Preset: Hide Network Noise is a good first click. See Filters for how it all fits together.

5. Look closer

Double-click any row (or right-click > Details) to see the packet broken down field by field in Packet Details.

6. Keep what you found

File > Save Data writes the grid to a text, tab or comma separated file.
