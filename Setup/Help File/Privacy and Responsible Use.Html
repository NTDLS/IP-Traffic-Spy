Privacy & Responsible Use

Only monitor what you are allowed to

IP Traffic Spy shows the contents of network traffic, which can include passwords, messages, personal details and other private information. Only use it on computers and networks that you own or have explicit permission to monitor. Laws on monitoring network traffic vary and can be strict. You are responsible for how you use it.

What the program does with your data

  • Captured packets are kept in memory only, and are lost when you exit or clear the grid. Nothing is sent to NetworkDLS.
  • The program writes to disk only when you ask: Save Data, Save Filters. A saved data file contains whatever was in the packets, so handle and delete it accordingly.
  • Your filters (and the AND option) are saved in the registry for the current Windows user, see Filters. They are never the captured data.
  • The program looks up host names for the addresses it sees, and for names in host rules. These are ordinary DNS requests sent to your computer's configured DNS server, which means that server can learn which addresses you are looking at. If that matters on your network, take it into account, or switch the lookups off with Actions > DNS Lookups. The lookups the program makes are hidden from the grid by default, see Menus.
  • The optional AutoUpdate tool installed with the program is separate and contacts the NetworkDLS website; the capture program itself does not.
