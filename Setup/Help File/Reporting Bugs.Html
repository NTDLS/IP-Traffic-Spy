Reporting Bugs

IP Traffic Spy runs on Windows 10 and Windows 11, see Requirements.

In the past releases of IP Traffic Spy few bugs have been reported but all found have been fixed. If IP Traffic Spy crashes or gives you an error, please take note of any error messages and if possible also note the circumstances in which it happened. Then visit the bug reporting page on NetworkDLS's website and submit any collected error information.

The following details help us find a problem quickly:

  • The program version (Help > About) and your version of Windows.
  • What you did, what you expected, and what happened.
  • Whether the problem happens on IPv4, IPv6 or both, and on which kind of adapter.
  • Your filters. Use Filters > Save Filters... and attach the file, they are plain text. (Please check the file for anything you would not want to share, such as private host names or addresses.)
  • A screenshot of the window, without any private data in it.

Please do not send captured packet data unless asked: it may contain private information.
