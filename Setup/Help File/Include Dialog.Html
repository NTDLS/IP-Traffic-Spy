Include Filters

    The Include Filters dialog allows you to set up filters that will be applied to encountered IP packets to decide whether they should be included in the packets you want to see. If you add no include filters, every packet is included.


Each box has an entry field, an Add button and a list with a Delete button. Press Enter in the entry field to add, and press the Delete key on a list to remove the selected item. Anything invalid is refused with a message and duplicates are ignored. Changes only take effect when you press Ok; Cancel throws them away.


Source IP Addresses source addresses to include. Addresses, wildcards and CIDR blocks, IPv4 or IPv6.
Destination IP Addresses destination addresses to include.
Source Ports source ports to include. A port, or a range like 1024-65535.
Destination Ports destination ports to include.
Advanced Rules any number of rules which combine several conditions. Hover over this section in the dialog for a full syntax reference, or see Advanced Rules.
Require every filter group that has entries to match (AND) changes how the groups combine, see below.

Notes:
    Within a list the entries are alternatives: a packet matching any entry of the list satisfies that list.
    Normally a packet is included if it satisfies any of the lists. With the AND option ticked, it has to satisfy every list that has entries.
    If the packet matches an Exclude Filter it is hidden regardless. See Filters Overview for the whole picture.
