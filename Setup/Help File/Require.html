NetworkA network adapter that is upWired adapter on a switch mirror port for network-wide visibility

Administrator rights are required. IP Traffic Spy reads packets through a raw socket, and Windows only allows that for administrators. Run the program as an administrator (the installer sets this up). If you do not, the status bar will report an error when connecting.

No driver or extra software is needed. A firewall or security product may prompt you the first time you run it.

Memory: every packet in the grid keeps its full contents so it can be inspected later. The grid is limited to 100,000 rows and about 512 MB of packet data, whichever is reached first; the oldest rows are discarded.
