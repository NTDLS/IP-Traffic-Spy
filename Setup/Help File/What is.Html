What is IP Traffic Spy?

IP Traffic Spy is a utility that allows you to easily watch the data that is being passed back and forth between your computer and other computers on the internet or network. It does this by reading the raw IP packets that are processed by your network adapter (both IPv4 and IPv6) and displaying them in a user friendly fashion.

Every packet is shown as a row in the Data Grid with its addresses, host names, ports, protocol, TCP flags and a readable view of the data. Double-click a row to open the Packet Details dialog, which breaks the packet down field by field, including DNS, HTTP and TLS.

A powerful filter system lets you cut a busy network down to only what you care about.
