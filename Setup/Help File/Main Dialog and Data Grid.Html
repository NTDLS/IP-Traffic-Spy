Main Dialog & Data Grid

    The "Main Dialog" or "Data Grid Dialog" is where IP packets are displayed that were encountered but not filtered out by one or more of your Inclusion or Exclusion filters (see Filters).

Columns

ColumnMeaning
Date, TimeWhen the packet was encountered.
ProtocolTCP, UDP, ICMP, ICMPv6, IGMP, or the name of another IP protocol (otherwise "Other").
S-IP, D-IPThe originating (source) and intended destination IP addresses. IPv4 or IPv6.
S-Host, D-HostThe host name of each address, found by reverse DNS. Shows ... while the lookup is pending, and stays blank if the address has no name. Every address is looked up once and remembered for the session.
S-Port, D-PortThe ports for TCP and UDP. Shown as 0 for packets with no ports (ICMP, other protocols, and fragments after the first).
TextThe printable text of the packet data. For DNS, HTTP and TLS this is replaced by a readable summary, e.g. DNS query A example.com, HTTP GET /index.html HTTP/1.1 | Host: example.com or TLS ClientHello SNI: example.com.
SizeThe overall size of the IP packet in bytes, headers included.
DirectionOutbound (sent from this computer), Inbound (sent to it) or Other (see Foreign packets below).
FlagsThe TCP flags that were set: SYN ACK FIN RST PSH URG ECE CWR. Empty for non-TCP packets.
TTLThe IPv4 time-to-live or IPv6 hop limit. Blank when unknown.
IP4 or 6: the IP version of the packet.
FragYes if the packet is part of a fragmented datagram.
Matched ByWhich include filter entries let this packet through. Blank when there are no include filters.

You can resize and drag the column headers to rearrange them.

Direction icons

     Sent Packets are packets that were sent from your computer.
     Received Packets are packets that were received by your computer.
     Foreign Packets are packets that were encountered by your network interface that are not to or from your computer. These are usually packets that are broadcast or multicast by various protocols, and data transmitted by older hubs (as opposed to switches).

"Your computer" means any address of the adapter you connected to, including all of its IPv6 addresses.

Status bar

From left to right:

  • The connection: Connected to ... (IPv4 + IPv6), (Not Connected), or the reason capture could not start.
  • Packets: everything the program has seen since connecting, and its total size.
  • Matchs: how many of those were shown in the grid.
  • DNS Cache / Backlog: how many addresses have been looked up, and how many lookups are still waiting.
  • The filter summary, for example Filters: 2 include, 5 exclude | Hidden: 1,204. Hidden counts packets your include/exclude filters removed. It also briefly shows confirmations such as "Added 1 exclude filter".

ActionsDNS LookupsTicked (the default): host names are looked up for the addresses seen. Untick it to stop all DNS lookups, both the reverse lookups that fill the host columns and the lookups for host names in rules. Names already learned are kept and still used; the host columns of new packets are simply blank. See Privacy.

FiltersTCP, UDP, Other ProtocolsTick to show, untick to hide that kind of packet.

They count towards "Hidden" in the status bar.

Right-click menu

Right-click the grid. With one or more rows selected you get:

  • Clipboard: Copy Text, Copy Source / Destination IP, Host or Port. Values are de-duplicated and sorted when several rows are selected.
  • Filters: Exclude and Include sub-menus, and Remove Filters Matching This Packet. See Right-click filters.
  • Details (single row): opens Packet Details.
  • Select All and Clear.

Notes

  • The grid holds up to 100,000 rows and about 512 MB of packet data. When either limit is reached the oldest rows are discarded to make room for new ones.
  • While paused, or while a dialog such as Packet Details or the filter dialogs is open, capture is suspended and packets arriving in the meantime are not recorded. Windows only buffers a small amount.
  • Double-clicking a row opens Packet Details.
