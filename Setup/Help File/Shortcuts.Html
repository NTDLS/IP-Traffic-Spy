Shortcuts

    The IP Traffic Spy application contains a few shortcuts to make your traffic browsing experience a little easier.

Main window

Key / actionDoes
Space BarPause and un-pause the Data Grid.
IOpen the Include Filter dialog.
EOpen the Exclude Filter dialog.
DeleteClear the grid.
F1Open this help file.
Double-click a rowOpen Packet Details for it.
Right-clickCopy, filter or inspect the selected rows.

Packet Details

KeyDoes
Alt+PPrevious packet.
Alt+NNext packet.
EscClose.

Filter dialogs

KeyDoes
Enter in an entry boxAdd the entry to its list.
Delete on a listRemove the selected entry.
TabMove to the next control.
