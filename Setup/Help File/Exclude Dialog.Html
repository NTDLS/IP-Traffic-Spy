Exclude Filters

    The Exclude Filters dialog allows you to set up filters that will be applied to encountered IP packets to decide whether they should be excluded from the packets you want to see.


Each box has an entry field, an Add button and a list with a Delete button. Press Enter in the entry field to add, and press the Delete key on a list to remove the selected item. Anything invalid is refused with a message and duplicates are ignored. Changes only take effect when you press Ok; Cancel throws them away.


Source IP Addresses source addresses to exclude. Addresses, wildcards and CIDR blocks, IPv4 or IPv6.
Destination IP Addresses destination addresses to exclude.
Source Ports source ports to exclude. A port, or a range like 1024-65535.
Destination Ports destination ports to exclude.
Advanced Rules rules which combine several conditions. Hover over this section in the dialog for a full syntax reference, or see Advanced Rules.

Notes:
    If the received packet matches any of the defined "Exclude" entries, the packet will not be written to the Data Grid Dialog even if it also matches one or more of the Include Filter entries.
    Exclude entries are always "any": there is no AND option here, but a single advanced rule can require several things at once, for example proto udp and port 53.
    For a quick start, Filters > Preset: Hide Network Noise fills in the common background chatter.
